# VITAL X

**Fitness, Activity & GPS Workout Tracking Application**

VITAL X is an independently developed fitness and activity-tracking application designed to help users understand their daily movement and record outdoor workouts using smartphone sensors and GPS.

I developed this project before beginning university as part of my self-directed journey in programming and software development.

## 🎯 Purpose

Many fitness applications present numbers without explaining how those values were obtained or how reliable they are.

VITAL X was designed around a different idea: provide useful activity data while clearly showing its source and confidence.

## ✨ Main Features

- Daily step tracking
- Distance estimation
- Activity score
- Data-confidence indicator
- GPS-based workout tracking
- Walking, running, and cycling modes
- Workout session history
- Local data storage on the device
- No account required for local workout records
- Clean and practical mobile interface

## 📍 GPS Workout Tracking

VITAL X can use GPS to record outdoor workout sessions.

Supported workout types include:

- Walking
- Running
- Cycling

The application is designed to track workout-related information such as distance and session activity while keeping saved workout data locally on the user's device.

## 📊 Activity & Data Transparency

The application displays activity-related metrics while also explaining where the information comes from.

Examples include:

- Step data from supported Android sensors
- Estimated distance based on available activity data
- A data-confidence indicator
- Activity scoring

This design helps users understand that not every measurement has the same level of reliability.

## 🔒 Privacy-Oriented Design

Workout records are stored locally on the device.

The application was designed to provide useful functionality without requiring a user account for locally stored workout sessions.

## ⚕️ Responsible Health Design

VITAL X is a fitness and activity application.

It is **not a medical diagnostic tool** and does not present its activity score as a medical diagnosis or recovery assessment.
